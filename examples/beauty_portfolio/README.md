# Beauty Portfolio

A synthetic, fully specified 12-taxon dataset used only to demonstrate Phylo3D-Trait presentation controls.

It is deliberately separate from the Eulipotyphla biological example. The node values here are illustrative; they are not empirical or reconstructed biological results.

## Files

- `tree.nwk` — ultrametric dated tree, root age 70.
- `node_values.csv` — complete tip + internal + root trait table, raw trait range 4.0–10.0.

## Why this example exists

The same data are rendered repeatedly in the Tutorial so that each figure changes only one display decision at a time:

1. full 0–10 visual baseline;
2. scientific baseline shifted from 0 to 4;
3. reversed trait-height direction;
4. fully opaque curtains;
5. 80% opacity;
6. alternate curtain coloring mode.

See the [Tutorial](../../docs/tutorial.md) for commands and screenshots.
